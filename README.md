## 🖥️ Terminal Commands

The portfolio includes a fully interactive terminal. Try these commands:

```bash
help       # List all available commands
whoami     # Display personal info
skills     # Show skill proficiency levels
certs      # List all 5 certifications
contact    # Display contact information
status     # Check availability status
scan       # Run a demo vulnerability scan
ping       # Test connection
date       # Display current date/time
clear      # Clear the terminal
```

> Supports **command history** (↑/↓ arrows) and **Tab autocomplete**.
